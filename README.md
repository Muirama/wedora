# Wedding Invitation Website

Site web interactif et élégant destiné à présenter une invitation de mariage numérique.

##  Présentation

Ce projet est une première version (V1) d'une invitation de mariage moderne et immersive.

Le site contient :

-  Hero avec les noms et la date
-  Notre histoire
-  Galerie photos
-  Compte à rebours
-  Programme de la journée
-  Lieu et carte
-  Formulaire RSVP
-  Footer
